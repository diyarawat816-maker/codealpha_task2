# Hangman Game

A simple text-based Hangman game written in Python.

## Features

- Uses 5 predefined words
- Randomly selects a word
- Allows up to 6 incorrect guesses
- Takes input from the user through the console
- Displays guessed letters and the current word

## Concepts Used

- Random
- While loop
- If-else statements
- Strings
- Lists

## How to Run

1. Make sure Python is installed.
2. Open the project folder in a terminal.
3. Run:

```bash
python hangman.py
